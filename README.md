# Minimal HD Wallet (Rust)

This project implements a simplified descriptor-based HD wallet engine in Rust.

## Features

- Descriptor parsing
- BIP32 public derivation
- Sequential address reveal
- Lookahead buffer maintenance

## Purpose

This project is built for educational purposes to understand
how wallet internals like BDK's KeychainTxOutIndex work.
